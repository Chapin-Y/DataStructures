# DataStructures

数据结构实验（C 语言）课程作业的源代码备份仓库。

## 关于本仓库

这个仓库是我在《数据结构》课程实验过程中写的代码，**属于本人实验报告的一部分**，不是完整可交付的项目，也不承诺任何工程质量。

建仓的目的很朴素，就三条：

1. **防丢** —— 作业代码只存在本机，硬盘坏了、误删了都是灾难，推到 GitHub 算是最省心的异地备份。
2. **可回退** —— 实验过程中改坏代码是常事，有版本历史就能随时退回上一个能跑的版本，不用靠复制粘贴出「final_final_v2」。
3. **练手 Git / GitHub** —— 顺便把 commit、branch、merge、push/pull 这些操作在真实的小项目上过一遍，比看教程有用。

所以仓库里的提交历史可能比较随意，会有「fix BUG」「改坏了先提交一下」这类信息，都是学习过程的痕迹，不必当真。

## 目录结构

```
.
├── linklist.cpp         # 单链表：初始化、插入、删除、查找、反转、归并
├── linkstack.cpp        # 链栈：初始化、入栈、出栈
├── linkqueue.cpp        # 链队：初始化、入队、出队、遍历输出、翻转
├── Applications01.cpp   # 线性表应用：随机生成、按基准值分割等
├── Applications02.cpp   # 综合应用：括号链表的生成与输出（当前构建目标）
├── CMakeLists.txt       # CMake 构建配置
└── README.md
```

各文件是独立的实验单元，`CMakeLists.txt` 里通过 `add_executable` 指定当前编译哪一个。切换实验时改这一行即可。虽然有点随意，但是我觉得能用就行，就懒得查更好的方法了。屎山代码也是代码嘛。

## 编译与运行

依赖 CMake ≥ 3.20、支持 C++20 的编译器（GCC / Clang / MSVC 均可）。

```bash
cmake -B build -DCMAKE_BUILD_TYPE=Debug
cmake --build build
./build/DataStructures        # Windows 下为 build\DataStructures.exe
```

用 CLion 的话直接打开项目根目录，等待 CMake 自动配置完成后点运行即可。

> 代码是 C 风格（`malloc`/`new` 混用、`printf`/`scanf`），用 `.cpp` 后缀只是为了让 CLion 的 C++ 工具链直接接手，不涉及面向对象特性。（绝对不是因为默认创建.cpp文件，而我懒得改）
